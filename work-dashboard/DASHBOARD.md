- 새 이슈: 프로젝트별 `프로젝트키-n` (H/S/M/...) 으로 채번 → 개별 파일 이슈로그 + 위 오픈이슈 테이블에 등재
- 해결 시: 개별 파일에 **해결 과정** 기록(감사추적), 대시보드 오픈이슈에선 제거
- 업무 진행: 개별 파일 "완료한 일" / "다음 액션"에 날짜와 함께 누적
