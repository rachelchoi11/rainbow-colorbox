## 0. 배포 상태 (2026-07-30 밤 갱신)
**강수아가 통합본(`d0e26e4` = 대표측 feedback + 강수아 root-improvement)을 prod에 배포 완료.**
→ **A(강수아분)·B(대표측분) 모두 지금 prod에서 바로 테스트 가능.** (이후 매니페스트 테스트 갱신 `6bef4ee`은 test-only라 재배포 불요)
- 적대적 검증 통과: 인라인 승인/반려가 결재권한 못 우회, 공유보드 POST 인증·ACL 보호, root개선 무회귀.
- 알림버튼 pointer-events 수정도 통합본에 포함(혹시 버튼 여전히 안 먹으면 배포 시점 확인 필요).

### 사전 준비
- 테스트 계정 여러 개(기안자 1 + 결재자 2 + 참조자 1). 결재선 구성용.
- **이동재 이사: ROLE_ADMIN 부여 후 반드시 로그아웃→재로그인**(토큰에 권한이 박혀서 재로그인 전엔 반영 안 됨). 재로그인 후 연차 문서 열람·출력 확인.

## A. 강수아 반영분 (지금 prod에서 바로 테스트)

### A-1. 임시저장함 (`/apr/temp`)
1. 기안 작성 중 **임시저장** → 사이드바/`/apr/temp` 진입.
2. 임시저장 문서가 목록에 뜨는지, **복원(이어쓰기)** 되는지.
3. 임시저장함엔 **본인의 미상신(DRAFT)만** 보이는지(남의 것·상신된 것 섞이지 않음).

### A-2. 법인 구분
1. 기안 작성 → **법인 선택란**((재)시안 / ㈜콘도매직스 / 그린시안(주)) 확인.
2. **법인 미선택으로 상신** 시도 → "법인을 선택한 뒤 상신해주세요" 로 막히는지.
3. **임시저장은 법인 없이도** 되는지(상신만 필수).

### A-3. 첨부 (볼륨 + PNG·XLSX) ★이전엔 전부 실패
1. 기안에 **PNG 이미지** 첨부 → 상신 → 결재대기함/상세에서 첨부가 **살아있는지**.
2. **XLSX(엑셀)** 첨부 → "허용되지 않는 파일 형식" **안 뜨고** 정상 첨부되는지.
3. 상신 후 **재배포**가 있어도 첨부 파일이 유지되는지(named volume).

### A-4. 상신 순서 / 첨부 유실 방지
1. 첨부 있는 기안 상신 → 작성창이 정상적으로 닫히고 다음 단계로 넘어가는지(예전엔 창이 안 닫혀 상신 여부 불명).
2. (경계) 상신 실패 상황에서 **첨부 없이 상신되는 일이 없는지**.

### A-5. ESC/닫기 데이터 보호
1. 기안 작성 중 내용 입력 → **ESC / 바깥 클릭 / X / 취소** → **확인창**이 떠 실수로 안 날아가는지.
2. 브라우저 새로고침/이탈 시 경고(beforeunload).

### A-6. 결재선 참조 검색
1. 결재선 편집에서 **참조 대상자 검색** → 결과가 뜨고 추가되는지(예전엔 검색 안 됨).

## B. 대표측 브랜치 반영분 (배포 후 테스트)

### B-1. 결재 알림 (참조·다음결재자·건너뜀) ★핵심
결재선 A(결재)·B(결재)·C(참조)로 상신 후:
1. 상신 → **A(첫 결재자)** + **C(참조)** 에게 알림 도착.
2. A 승인 → **B에게 "결재 요청" 알림**(이전엔 B가 자기 차례인지 몰랐음).
3. B가 A단계를 건너뜀 → **A에게 "결재 건너뜀" 알림**.
4. 최종 승인 → **기안자에게 결과 알림**.
   (헤더 종/알림 페이지 `/notifications`에서 확인)

### B-2. 진행함 인라인 승인/반려
1. 결재자 계정 → **결재 진행함**에서 내 차례 문서 카드에 **승인/반려 버튼**이 바로 보이는지.
2. 승인/반려를 **결재대기함 이동 없이** 처리, 목록 갱신.
3. 내 차례 아닌 문서엔 버튼 안 보임 / 읽기전용 계정엔 숨김.

### B-3. 공유보드 이미지 첨부
1. **공유보드** 작성창 → **이미지 첨부** → 게시 → 피드에 **썸네일**, 클릭 시 원본.
2. 다른 부서 이미지는 접근 차단(권한).

### B-4. 에디터 텍스트 정렬
1. 기안 본문 에디터 툴바의 **좌/가운데/우 정렬** 버튼 → 문단 정렬 적용.
2. **표 셀 안 텍스트**도 정렬되는지.
3. 출력(PDF/Word)에도 정렬 반영되는지.

### B-5. 첨부 드래그앤드롭
1. 기안 첨부 영역에 파일을 **끌어다 놓기** → 첨부되는지(드래그 중 테두리 강조).

### B-6. 휴무 라벨 / 진행함 시간 / 주간보고 보고일자
1. 휴무변경 문서: 라벨이 **기존휴무일·변경휴무일**(화면+출력).
2. 결재 진행함 카드 접수정보가 **날짜+시간**.
3. 주간업무보고 양식에 **보고 일자** 필드 존재.
