# 📌 work-dashboard 사용 규칙 (모든 터미널 공통)

이 폴더는 Rachel의 **전 프로젝트 공용 진실원천(single source of truth)**. 어느 터미널/세션에서 작업하든, 끝나면 여기를 갱신한다. 노션은 이걸 비추는 뷰일 뿐.

> ⚠️ Claude 메모리(`~/.claude/projects/.../memory/`)는 **프로젝트별로 분리**되어 터미널 간 공유 안 됨. 터미널 간 공유는 **반드시 이 폴더 파일로** 한다.

## 구조
```
work-dashboard/
├── DASHBOARD.md     ← 마스터: 이번 시기 우선순위 + 크로스 프로젝트 오픈이슈 + 한 줄 현황
├── hivemind.md      ← 프로젝트별: 완료한 일 / 진행 중 / 다음 액션 / 이슈 로그
├── silvertoktok.md
├── hmusic.md
├── operations.md   ← 🛠️ 운영: 전 프로젝트 상위의 체계·프로세스·도구 작업 기록 (이슈 OPS-n)
└── ... (sian, caresafe 등 추가)
```

> **운영(operations.md)**: 특정 프로젝트에 속하지 않는 상위 작업(트래킹 체계, 계약·일정 관리 구조, 공용 도구, 인수인계 인프라 등)은 여기에 기록.

## 작업 끝낼 때 (각 터미널이 하는 일)
1. **자기 프로젝트 md 갱신**
   - `완료한 일`에 날짜와 함께 한 줄 추가
   - `다음 액션` 체크박스 갱신 (`[ ]`→`[x]`)
   - 새 이슈/해결은 `이슈 로그` 표에 반영
2. **DASHBOARD.md 동기화**
   - 새 오픈이슈 → "전체 오픈 이슈" 표에 등재
   - 해결된 이슈 → 오픈이슈 표에서 제거 (해결 과정은 프로젝트 md에 남김)
   - 우선순위/한 줄 현황 바뀌었으면 갱신
   - 상단 "최종 업데이트" 날짜 갱신

## 규칙
- **이슈 채번**: 프로젝트 약자-번호 → 하이브마인드 `H-n`, 실버톡톡 `S-n`, 현대음악 `M-n`, 시안 `SI-n`, 케어세이프 `C-n`, 운영 `OPS-n`
- **상태 이모지**: 🔲열림 · 🔄진행 · ✅해결 · ⏸️보류
- **해결 시**: 프로젝트 md 이슈로그에 *해결 과정*을 반드시 남긴다(감사추적). 대시보드 오픈이슈에선 뺀다.
- **날짜**: 절대표기(2026-06-13). "오늘/내일" 금지.

## 정리 허브
- **bizplan-ai 터미널** = 일정·전체 정리 허브. "싱크/정리해줘" 하면 전 파일 읽고 재조정.
- 다른 터미널은 자기 프로젝트만 갱신해도 됨 — 허브가 종합한다.
