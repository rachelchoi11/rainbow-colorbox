# 별의아이들 (Gleam)
## 교사를 위한 5분 학생 강점·관심 발견 도구
**제8회 교육공공데이터 AI활용대회 · 일반부 출품작 · 1차 서면심사용 기획서**

---

## 0. 한 줄

전국 6,000개 학교에 매년 발생하는 **80만 명의 느린학습자**를 학교가 *발견·매칭*하는 데 걸리는 시간을 **한 학기 → 한 시간**으로 줄이는 교사용 AI 도구.

---

## 1. 문제

### 1.1 데이터로 본 사실

- 한국 학생의 **약 13.6%(약 80만 명)**가 학습부진·기초학력 미달로 분류된다 (교육부 2024 기초학력진단 보고서).
- 이 중 학교가 *적시에* 발견·지원에 매칭하는 비율은 **체계적 통계 부재**. 시도별 학습종합클리닉센터 의뢰 건수와 부진학생 수 사이의 격차는 5~10배 수준 (KLISS·시도교육청 자료 종합).
- **학교 한 학급당 부진학생 1~3명**, 담임은 **연 200시간 이상의 행정 부담**(교총 2024). 부진학생 한 명을 발견·관찰·의뢰서 작성하는 데 드는 시간은 *불가능에 가깝다*.

### 1.2 기존 시스템의 실패점

- **국가수준 학업성취도 평가**: 학교 단위 통계만 산출. 개별 학생 진단 불가.
- **기초학력진단검사**: 결핍 측정에만 초점. 학생의 *흥미·강점*은 측정하지 않음.
- **교사 관찰**: 시간 부족. 한 학생당 분기 1회도 어려움.
- **학습종합클리닉센터**: 시도별 1~5개. 의뢰가 들어와야 작동. 의뢰 자체가 병목.
- **AI 학습 도구**: 거의 모두 *학생용*. **교사 행정 부담을 줄이는 AI는 거의 없다**.

### 1.3 결정적 통찰

> 부진학생을 *모르는 게* 문제가 아니라, **알아내고 매칭할 시간이 학교에 없는 게 문제**다.

별의아이들은 *학생을 진단*하지 않는다. **교사가 학생을 5분 안에 보게 하는 도구**다.

## 2. 해결책 (제품 개요)

### 2.1 워크플로우 (교사 시점)

```
1. 교사가 학급 학생 목록을 한 번 등록 (NEIS 학교 코드로 자동 매칭)
   ↓
2. 학생이 자기 단말에서 5분 게임 4종 수행 (수업 시간 외)
   - 단어 폭포 / 이야기 이어쓰기 / 어떤 장면이 끌려? / 시간과 패턴
   ↓
3. AI가 게임 결과 + 학교알리미 학교 단위 분포 + 도서관정보나루 또래 트렌드를 종합
   ↓
4. 교사 화면에 학생별 한 페이지 카드 자동 출력
   - 강점 영역 추정 (탐색적 신호, 신뢰구간 표시)
   - 흥미 영역 추정 (Holland 코드)
   - 학교 또래 분포에서의 위치
   - 추가 관찰 권장 포인트 3개
   - 후속 조치 제안 (학습종합클리닉 의뢰 후보 / 영재 추천 후보 / 일반 보강)
   ↓
5. 교사가 검토 후 의뢰 결정. 시스템이 가까운 학습종합클리닉 매칭 + 의뢰서 초안 자동 생성
```

### 2.2 핵심 가치 명제

| 사용자 | 가치 |
|---|---|
| 교사 | "학급 30명 분 부진학생 발견·관찰 보고서가 자동으로 나온다" |
| 학생 | "거부감 없는 5분 게임. 약점이 아닌 *나만의 빛*을 발견" |
| 학교 | "학교 단위 학습부진 분포·추세를 자동 시각화" |
| 교육청 | "관할 학교의 미발견 부진학생 + 학습클리닉 매칭 사각지대 자동 식별" |

## 3. 활용 데이터 (5종 결합 + 입력단 통합)

### 3.1 데이터 결합 다이어그램

```
[학생 게임 결과]                   [교사 학급 입력]
         │                                │
         ▼                                ▼
   AI 1차 분석 ◄──────── 학교 단위 컨텍스트 주입 ────────
                              │
        ┌──────────┬──────────┼──────────┬──────────┐
        ▼          ▼          ▼          ▼          ▼
   도서관정보나루  NEIS    학교알리미    KLISS    어린이청소년도서관
   인기대출+ISBN   학교메타  도서관시설   통계      사서추천
   또래분석      +학사일정  +다문화비율  +학교도서관 (큐레이션)
                                       평가지표
```

### 3.2 데이터별 활용 시나리오

| 데이터 | 출처·인증 | 활용 시점 | 시너지 |
|---|---|---|---|
| **도서관정보나루** `loanItemSrch`, `usageAnalysisList` | data4library.kr · 무료 즉시 인증 (30,000회/일) | **입력단** — 학생 ISBN 이력으로 흥미 영역 추정. **출력단** — 강점 영역 매칭 도서 추천 | 학생 *읽은 책*이 강점·흥미 시그널이 됨 |
| **NEIS 교육정보 개방** | open.neis.go.kr · 무료 즉시 인증 | **입력단** — 학교 코드 → 학교 메타 자동. 학사일정 → 진단 시기 추천 | 학교명·학년 입력 즉시 메타 매칭 |
| **학교알리미** | schoolinfo.go.kr · 무료 키 | **입력단** — 학교별 도서관 보유도서·학생수·다문화 비율 → 결과 해석 컨텍스트 | "이 학교 1인당 장서가 평균의 60%"같은 *학교 단위 격차* 시각화 |
| **KLISS 학교도서관 통계** | libsta.go.kr · 파일 다운로드 | **입력단** — 학교도서관 평균치 비교 | 학교 단위 추세 분석 |
| **국립어린이청소년도서관 사서추천** | data.go.kr/15104976 · 무료 | **출력단** — 강점 + 흥미 매칭 후 *사서 검증된* 추천 큐레이션 | AI 추천 + 인간 큐레이션 동시 |

### 3.3 위키문헌 본문 (저작권 안전 라이브러리)

- 한국 근대문학 만료작 25,000+ 문서 (이상·김유정·현진건·윤동주·채만식 등)
- Project Gutenberg + Standard Ebooks 영문 75,000권+
- 중·고 교과서 정전 PD 커버리지 ~65%, 초등 ~20%
- 모드 A "본문 직독" + 모드 B "메타데이터 + 학생 자작물"의 듀얼 구조로 초등도 합법 작동

## 4. AI 핵심 기능

### 4.1 5분 게임형 진단 4종

| 게임 | 시간 | 측정 시그널 | 어뷰징 방어 |
|---|---|---|---|
| **단어 폭포** | 60초 | 언어 유창성, 의미 클러스터, 추상도 | 단어 수 + 시간 분포 일관성 |
| **이야기 이어쓰기** | 120초 | 인물 감정·동기 묘사, 갈등 처리, 시각 묘사 | 길이·어휘 복잡도 합리성 |
| **어떤 장면이 끌려?** | 90초 | 흥미 코드, 시각/체험/관계/자연 선호 | 응답 시간 + 일관성 |
| **시간과 패턴** | 120초 | 리듬 일관성, 시간 추정, 수열 추론 | 객관 정답·오차 측정 가능 |

각 게임 결과는 Claude Sonnet 4가 **탐색적 신호**(0~10)로 변환. 절대값이 아닌 *학교·학년 또래 분포 안에서의 위치*로 해석.

### 4.2 통합 분석 엔진

- **8지능(가드너) → OECD 21세기 스킬 + Holland 코드** 이중 매핑
- 가드너는 *내부 표상*으로 유지(추상화 도구), 출력 표면은 OECD 4영역(창의·비판·협업·소통)과 Holland 6코드(R/I/A/S/E/C)로 표시
- 학교 단위 또래 분포(NEIS·학교알리미)를 Claude 시스템 프롬프트에 컨텍스트로 주입 → "이 학생은 같은 학년 또래의 상위/중위/하위 N% 위치" 식 상대화

### 4.3 교사 카드 자동 생성

- 학생당 1쪽 PDF/DOCX
- 강점 신호 TOP 3 (불확실성 ±1.5 명시)
- 흥미 코드 (Holland)
- 학교 또래 분포 위치
- **추가 관찰 권장 포인트 3개**
- 후속 조치 시나리오:
  - 학습종합클리닉 의뢰 후보 → 가까운 센터 자동 매칭 + 의뢰서 초안
  - 영재교육원 추천 후보 → 교사 검토 후 결정
  - 일반 보강 → 강점 기반 활동 5개 + 도서관정보나루 매칭 도서

### 4.4 학습종합클리닉 자동 매칭

- 시도교육청별 학습종합클리닉센터 분포(공공데이터)와 학생 거주지 결합
- 매칭 기준: 거리·전문 영역·대기 인원
- 의뢰서 초안 자동 작성 (BizPlanAI에서 이식한 DOCX 생성 파이프라인)

## 5. 학술적·윤리적 방어선

### 5.1 가드너 다중지능의 한계 직시

학계 비판(Visser et al. 2006: 다중지능은 단일 g 요인으로 수렴)을 인정. 본 시스템은:
- 가드너를 **내부 분석 프레임으로만** 사용 (요인분석상 분리 불가)
- 사용자 노출 표면은 **OECD 21세기 스킬 + Holland 코드** (정책 정합)
- 모든 출력에 **"1회 5분 탐색 결과 — 진단 아님" 명시**
- 절대 점수 임계값(8점) 트리거 폐기. 상대 위치 + 인간 검토만으로 의사결정.

### 5.2 책임 구조

- **모든 의뢰서/카드는 교사 검토 후 발행**. AI 단독 자동 발송 금지.
- **거짓양성 방어**: 응답 시간·일관성·어휘 복잡도 검증으로 어뷰징 1차 차단.
- **알고리즘 공정성**: 다문화 학생 가중치 사용 안 함. 다문화 변수는 *해석 신뢰도 페널티*("이 결과의 한국어 의존도가 높아 불확실성 큼")로만 작동.
- **추적 루프(Phase 2)**: 6개월 후 학생 후속 결과 입력 → 시스템 신뢰도 자기검증.

## 6. 시연 (로컬 데모)

- Repo: `bookbook-ed/gleam` (로컬 데모 — 배포 미정)
- Stack: Next.js 15 + TypeScript + Prisma(SQLite) + Claude Sonnet 4
- 포함:
  - 학생 등록 + 학교 메타 자동 매칭
  - 4개 게임 순차 수행 UI
  - AI 강점·흥미 분석 + 교사 카드 출력
  - 도서관정보나루 추천 + 사서추천 큐레이션
  - 학부모/교사 리포트 DOCX 자동 생성
  - 학습종합클리닉 매칭 (의뢰서 초안 포함)
- 시연 시나리오 5분: 가상 학생 3명(저학년 1, 고학년 1, 중학생 1) 진단 → 카드 출력 → 학습클리닉 의뢰서 다운로드.

## 7. 사회적 효과 (정책 시그널)

| 단기 (1년) | 중기 (3년) | 장기 (5년) |
|---|---|---|
| 시범 학교 5교 도입 → 부진학생 발견 사이클 1학기 → 1주 단축 | 시도교육청 1~2개 단위 도입 → 부진학생 발견율 N → M% | 학습종합클리닉 의뢰 사각지대 해소, 영재 발굴 다양화 |

### 7.1 정책적 메시지

> "결핍을 측정하는 시스템에서 강점·흥미를 함께 측정하는 시스템으로. 학생을 *진단*하는 도구가 아니라 *교사가 학생을 1주일 안에 보게 하는* 도구로."
