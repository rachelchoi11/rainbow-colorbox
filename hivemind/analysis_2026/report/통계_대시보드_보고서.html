1. 분석 배경

기존에 사용하던 Power BI 통계 파일(2025년 자체 출간작 매출 정리)의 내부 리포트 정의를 추출하여, 담당자가 어떤 지표를 어떤 형태로 보고자 했는지 파악했습니다. 이를 기준으로 신규 웹 대시보드의 통계 구성을 설계하고, 기존 의도를 충족하면서 정산 솔루션의 강점을 더한 지표를 구현했습니다.

※ Power BI Desktop은 Windows 전용으로 macOS에서 직접 열 수 없으나, 파일 내부 구조(리포트 정의)를 추출하여 구성 의도를 분석했습니다. 신규 대시보드는 웹 기반으로 재구현되어 운영체제 제약이 없습니다.

5. 시연 시나리오

아래 순서로 시연하면 표준화–분석–정산–검증의 전체 흐름을 약 10분 내에 보여줄 수 있습니다. 모든 화면은 2026년 2–3월 실데이터로 동작합니다.

#화면시연 내용 / 설명 멘트
1업로드‘샘플로 둘러보기’ 클릭. “유통사 28곳, 형식이 제각각인 정산서 69개를 그대로 넣어 자동 표준화합니다.”
2정산 요약작가 지급 대상 정산액과 월별 매출·정산액 막대 제시. “원본 합계와 자동 대사해 40/40 일치 검증을 거친 실데이터입니다.”
3통계 분석매출→정산 폭포·유통사 도넛·작가 파레토(상위 10명 36%) 짚기. 상단 유통사 필터 변경 시 차트 즉시 갱신 시연.
4작가별 (핵심)상위 작가 클릭 → 작품×유통사×월별 정산액과 산출 근거 드릴다운. “작가에게 얼마를 왜 줘야 하는지 유통사 원본까지 추적됩니다.”
5정산서 발행유통사 선택 → ‘정산서 발행’ → 원천징수·실지급액 포함 명세서 → 인쇄/PDF.
6미매칭 AI (핵심)AI 제안 탭에서 ‘월야환담 광월야’ 등 신뢰도·근거와 함께 제안 → 승인 시연 → 결정 히스토리 확인. “AI가 다른 유통사·유사 작품에서 작가를 찾아 제안하고, 승인하면 이후 자동 반영되며 모든 결정이 이력으로 남습니다.”
7통합 검색‘월야환담’ 검색 → 유통사별 작가 보유 여부(✓) 확인. “한 작품이 어느 유통사에 어떤 작가로 들어있는지 한눈에 봅니다.”

6. 요약

기존 Power BI 대시보드가 보여주던 매출 분석 지표를 대부분 반영하고, 정산 솔루션의 목적에 맞는 작가 중심 분석(작가별 정산·근거, 정산 집중도)과 매출–정산 구조 분석, AI 미매칭 제안을 추가했습니다. 운영체제 제약이 없는 웹 기반으로 재구현하여 유통사·기간 필터에 실시간 연동되며, 출간연도·장르 등 원천 데이터의 한계가 있는 항목은 사유와 보완 방안을 함께 정리했습니다.

데이터 취급 안내. 본 보고서에는 실제 매출·정산액 및 작가·작품 정보가 포함되어 있습니다. 정산 당사자 간 내부 검토 목적으로만 사용하며, 제3자에게 재배포·공유하지 않도록 유의해 주시기 바랍니다.
