# 정산 표준화 솔루션 (웹앱 MVP)

출판사가 받는 유통사별 정산서(파일)를 업로드하면 → 표준화 → **작가별 정산 금액과 근거** + 미매칭 보드를 보여주는 웹 애플리케이션.

## 실행

```bash
cd analysis_2026/webapp
pip install fastapi uvicorn python-multipart pandas openpyxl xlrd
uvicorn app:app --host 127.0.0.1 --port 8731
# 브라우저: http://127.0.0.1:8731/
```

첫 화면에서 **"26년 2·3월 샘플로 둘러보기"** 로 실데이터 데모(69개 파일, 145,018행)를 바로 확인 가능.

## 구조

```
webapp/
  app.py          FastAPI 엔드포인트 (업로드/요약/유통사/작가/미매칭/검증/내보내기)
  engine.py       표준화 엔진 — 기존 pipeline 재사용 + 매칭/집계
  static/         프론트엔드 (핀테크 스타일 단일 페이지)
    index.html  app.js  style.css
  data/           사용자 등록 별칭(aliases.json) 영속화
../pipeline/      파서 25종·정규화·검증 (engine이 import)
```

## 기능 (GPT 협의로 우선순위 확정)

- **P0** 파일 업로드 → 표준화 → 원본 합계 대사 검증 → **작가별 정산 + 근거 드릴다운**(어느 유통사/작품에서 얼마, 제공값/계산값 구분) → 미매칭 보드(작가·레이블 등록 → 재매칭)
- **P1** 유통사별 정산 요약, 월별 추이 대시보드
- **P2** 엑셀 내보내기

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/upload` | 정산서 다중 업로드 → 세션 생성 |
| POST | `/api/load_sample` | 26년 2·3월 원본 데모 로드 |
| GET | `/api/summary` | 월 요약·추이·검증 |
| GET | `/api/distributors` | 유통사별 |
| GET | `/api/authors` | 작가별 (검색·월 필터) |
| GET | `/api/author?name=` | 작가 상세 + 근거 |
| GET | `/api/mismatch` | 미매칭 큐 |
| POST | `/api/mismatch/register` | 작가·레이블 등록 → 재매칭 |
| GET | `/api/verify` | 파일별 합계 대사 내역 |
| GET | `/api/export` | 통합 엑셀 |

## 알려진 제약 (운영 전 보완 대상)

- 세션·별칭은 단일 프로세스 인메모리/단일 파일 — 단일 출판사(단일 테넌트) MVP 기준. 다중 사용자 동시성·인증은 운영 전 추가 필요.
- 별칭(aliases.json)은 전역 공유 — 단일 출판사에선 의도된 동작(대조표 누적 자산).
- **Codex 적대적 검증 미완**: CLI 계정 인증 제한으로 미실행. 클라이언트 배포 전 Codex 검증 필요(모두플랜 규약).
