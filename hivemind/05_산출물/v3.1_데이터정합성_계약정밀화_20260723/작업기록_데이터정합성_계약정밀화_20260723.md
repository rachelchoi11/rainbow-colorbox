# 정산 데이터 정합성·계약 정밀화 작업기록 (v3.1)

- 작성일: 2026년 7월 23일
- 작성자: 최혜윤 (기획·PO 총괄) · rachel@hive-mind.kr
- 대상: 개발본(feat 브랜치), v3(2026-07-20) 후속 작업분
- 데이터 범위: 2026년 1~4월 정산서 · 유통사 31곳 · 431,296행

## 1. 개요

v3 서비스화 전환 이후, 출판사·레이블 매핑의 정합성을 데이터 단위로 검증하고 계약 관리의 작품 범위 처리를 정밀화함. 모든 변경에서 회귀 불변식(431,296행 · 완전매칭 99.50% · 원본 대사 검증 86건)은 유지됨.

## 2. 유통사 레이블 오인식 수정 (에피루스)

- 증상: 미매핑 레이블 824건 중 586건이 "부도덕한 밀애\*세트구매\*" 류 책 제목이었음.
- 원인: 에피루스 정산서에 출판사 열이 없고, 파서(`specs.py` columns_pos)가 4번 열(작품 부제)을 레이블로 읽음.
- 근거: 본부장 매핑표 127행 = 레이블 "에피루스" → 출판사 "블루마운틴소프트". 에피루스는 단일 출판사 전용 유통 채널.
- 조치: `specs.py`에 `label_const="에피루스"` 지정(4번 열 제외), `run.py`에 상수 레이블 적용 로직 추가. frozen 샘플 2,338행 label을 "에피루스"로 정정(수정 파서 출력과 동일).
- 결과: 테넌트 843 → 258곳(586 제목 흡수). 회귀 불변식 완전 동일.

## 3. 유통사 전수 점검

- 목적: 에피루스와 동일한 "제목=레이블" 오인식이 다른 유통사에도 있는지 확인.
- 결과: 수정 후 전 유통사 제목형 레이블 0건. 에피루스가 유일했음.
- 나머지 플래그(무툰·노벨피아·문피아·조아라·큐툰 등)는 "빈 레이블" = 다출판사 애그리게이터(유통사). 출판사 정보 미제공이 정상이며, 매칭 엔진이 작품명↔마스터 대조로 72~99% 복원.
- 미복원 잔여 = 마스터 미등록 신작뿐, 전체의 0.08%로 극소.

## 4. 출판사–레이블 매핑 통합

- 절차: 미매핑 정제 CSV 238건을 본부장 확인 요청 → 215건 회신, 23건 미상.
- 데이터 심층분석(미상 23건): 같은 작품이 이미 매핑된 레이블에 존재하는지로 판정(작가 교차는 노이즈로 배제).
  - 확정 3건: Miyoo → AP북스, 마미 → 스토리야, 엉뚱한앙마 → 뿔미디어.
  - 잔여: 후보(작가명 오입력) 2 · 유력(근거 약함) 1 · 추정(작가교차) 6 · 미상 11.
- 오입력 색출: 레이블 자리 작가명 5건(창작집단 뻘·리즐리안·마미·배파·엉뚱한앙마), ISBN 1건(9.79E+12 → 도서출판 윤송).
- 통합 매핑표(`출판사_레이블_매핑_통합_20260723`): 기존 xlsx 281 + 본부장 174 + 데이터 확정 3 = **458 레이블 → 158 출판사**. 충돌 1건(JK미디어 → 작가컴퍼니, 본부장 회신 우선).
- 반영: 앱 매핑(label_publisher_map.json) 282 → 458. 재시드 결과 테넌트 258 → **144곳**(다레이블 출판사 64).

## 5. 계약 작품 범위 정밀화

- 여러 작품 지원: 작품 범위를 단일 문자열 → 다중 항목(OR)으로 확장. 지정한 작품명 중 하나라도 title에 포함되면 매칭. 포함매칭이라 권차·외전 자동 포함.
- UI: 레이블과 동일한 칩(추가/삭제) 방식으로 통일. 비우면 작가 전체 작품.
- 중복 경고: 같은 작가의 계약이 실제 매칭 작품(정산 행) 기준으로 겹치면 이중 배분 위험 경고(상단 배너 + 행 배지 + 겹친 금액 툴팁). 문자열 비교가 아닌 실제 행 교집합으로 판정해 오탐 없음.
