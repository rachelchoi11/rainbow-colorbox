## 한눈에 — 무엇이 달라졌나
배포본(v2)은 정산 데이터를 분석하는 **도구**였다. 개발본(v3)은 출판사가 로그인해 사용하는 **정산 서비스**로 전환하고, 계약·회원·정산 마감·분석을 포함한다.

| 구분 | 배포본(v2) | 개발본(v3) |
| --- | --- | --- |
| 성격 | 정산 분석 도구 | 멀티테넌트 정산 서비스 |
| 접속 | 공용 비밀번호 | 회원 로그인 + 역할별 권한 |
| 출판사·계약 | 정산 데이터에서 파생 | 영속 마스터(계약·유통사 분리 관리) |
| 계약 | 요율 직접 지정 | 계약 넘버링·상태·유효기간·지급 대상 |
| 정산 결과 | 실시간 "예상"만 | 정산 마감(확정 스냅샷)·지급 상태 |
| 데이터 격리 | 없음 | 출판사별 서버측 격리 |
| 저장 | JSON 파일 | SQLite(안전·영속) |

## 새로 생긴 것

**① 회원·권한·온보딩**
- 운영사(하이브마인드: 최고관리자/운영자/뷰어) · 계약사(출판사관리자/담당자)
- 계약사 계정 발급(이메일 초대) → 최초 접속 동의 → 정보 입력 → 워크스페이스
- 계약사 화면은 계약사명이 주 브랜드(하이브마인드는 제공처로 표기)

**② 계약 체계**
- 계약번호 = 출판사-콘텐츠-웹소설/웹툰-계약유형-콘텐츠유형(예: `0001-AA001-N-2-01`)
- 상태(초안/확정/종료)·유효기간·지급 대상(작가/출판사)·작품 범위·중복 경고·선인세(MG)·계약서 첨부
- 정산 데이터에서 기존 계약 일괄 등록(소급 온보딩)

**③ 정산 마감/원장**
- 초안 → 확정(금액 고정 스냅샷) → 지급. 선인세는 이월 원장으로 이중 차감 방지
- 명세서(작가 지급)를 계약 기반 산식으로 통일

**④ 성과 분석**
- 월별 추세·전월 대비·유통사 성과(정산율·성장)·상위 작가/작품·집중도

**⑤ 운영 자동화**
- 정산서 수집 현황판(유통사×월: 검증/미검증/미수신)
- 이상 탐지(급변·누락·음수·합계 불일치)
- 마감 현황·기한 리마인더

**⑥ 보안·안정성**
- 출판사별 데이터 서버측 격리, 감사 로그, 비밀번호 재설정, SQLite 영속
- 외부 계약사 오픈을 위한 최소 안전선 통과

## 구조

```
관리자(하이브마인드) ─ 운영자 콘솔
 ├ 고객·출판사: 출판사 관리 · 레이블별 정산
 ├ 정산 분석: 요약 · 유통사/작가/작품 · 성과 분석 · 통합 검색
 ├ 정합성·엔진: 미매칭 · 연구소 · 수집·점검 · 마감 현황
 └ 운영·회원: 회원·권한 관리
계약사(출판사) ─ 워크스페이스 (자사 데이터만)
 ├ 정산 진행: 대시보드 · 유통사 관리 · 정산서 투입
 ├ 정산 결과: 유통사/작가/작품 · 통계 · 성과 분석
 ├ 계약·명세: 계약 관리 · 정산 마감
 └ 회사: 회사 정보(정산 계좌 등) · 사용자 관리
```

---

## 시연 순서
1. 로그인 → (계약사) 동의·정보 입력 온보딩
2. 운영자 — 출판사 관리 · 회원·권한 관리(승인·계정 발급)
3. 계약 관리(넘버링·상태·지급 대상) → 정산 마감(확정)
4. 성과 분석(추세·유통사 성과) · 수집·점검(이상 탐지)
5. 계약사 로그인 → 자사 데이터만 보이는 격리 확인
