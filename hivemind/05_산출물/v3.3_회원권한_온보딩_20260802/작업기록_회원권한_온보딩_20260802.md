## 0. 무엇을 만들었나 (한눈에)

출판사 정산 서비스에 **회원·권한 체계**를 넣음. 3자 구조 "작가 – 출판사(계약사) – 관리자(하이브마인드)"를 실제 로그인 계정으로 구현.

1. **운영사(하이브마인드) 회원가입·승인·권한 관리**
2. **계약사(테넌트)에게 계정 발급**(이메일 초대)
3. **계약사 최초 접속 흐름**: 동의 화면 → 자기 정보 입력 → 워크스페이스
4. **계약사 자사 사용자 관리**(담당자 초대)
5. **역할 기반 접근 제어(RBAC)** — 운영자 전용 기능을 계약사가 못 건드리게 차단

## 1. 역할·권한 체계 (sian 관례 참고)

### 조직 유형과 역할
| 조직 | 역할 | 설명 |
| --- | --- | --- |
| 운영사(하이브마인드) | 최고관리자 | 전 기능 + 회원/권한 관리 + 승인 |
| 운영사 | 운영자 | 출판사·계약·정산 운영, 계약사 계정 발급 |
| 운영사 | 뷰어 | 조회 전용 |
| 계약사(출판사·유통대행사) | 출판사관리자 | 자사 정보·계약·정산 관리, 자사 사용자 관리 |
| 계약사 | 담당자 | 자사 정산·계약 조회 |

### 권한 키 (resource:action) — 역할별 매핑
- 운영: `members:manage` `members:approve` `roles:manage` `invites:issue` `tenants:manage` `contracts:manage` `settlement:upload` `settlement:view` `lab:manage`
- 계약사: `org:manage_own` `members:manage_own` `settlement:view_own` `contracts:view_own`
- 최고관리자 = 전 권한. sian에서 채택한 원칙: **status=활성만 로그인, 최고관리자 바이패스, 동의 전 차단**.

## 2. 핵심 흐름

### A. 운영사 회원가입 → 승인
- `/register`에서 이메일·비밀번호·이름으로 가입 → 상태=**대기**.
- **최초 가입자는 최고관리자로 자동 활성화**(부트스트랩). 이후 가입자는 최고관리자 승인 필요.
- 최고관리자가 회원 관리 화면에서 **승인/반려 + 역할 지정**.

### B. 계약사 계정 발급(초대)
- 운영자가 회원 관리 → "계약사 계정 발급"에서 **계약사(출판사) + 이메일 + 역할** 지정 → **초대 링크** 발급(이메일 전달 상정, 링크 자동 복사).
- 계약사 담당자가 `/invite/{token}` 접속 → 이름·비밀번호 설정 → 계정 활성화.
- **그 테넌트의 첫 계정은 자동으로 출판사관리자**.

### C. 계약사 최초 접속 (2단계 게이트)
- **① 동의 화면**: 개인정보 수집·이용 / 정산 데이터 목적 / 보안 약관. 동의 전에는 서비스 진입 차단(sian 동의 게이트 방식).
- **② 정보 입력(온보딩)**: 담당자 이름·연락처 확인·입력.
- 두 단계 완료 후 자사 워크스페이스 진입.

### D. 계약사 자사 사용자 관리
- 출판사관리자는 자사 사용자만 조회·초대(담당자)·정지 가능. 타사·운영사 회원은 안 보임.

---

## 3. 접근 제어(RBAC) 적용

- **인증 게이트**: 회원이 존재하면 로그인 필수(미로그인 → `/login`, API는 401). 회원이 하나도 없으면 부트스트랩(`/register`만 허용).
- **엔드포인트 권한 가드**: 운영자 전용 쓰기(출판사 생성/수정, 계약 생성/수정/삭제·일괄, 유통사 설정, 발견 시딩)에 권한 검사 추가. 계약사 계정은 호출 시 **403**.
- **검증(실측)**:
  - 계약사 → 출판사 생성 API: **403 차단** ✓
  - 계약사 → 계약 생성 API: **403 차단** ✓
  - 계약사 → 자사 사용자 조회: **200 허용** ✓
  - 운영자 → 출판사 생성·회원 목록: **200 허용** ✓

## 4. 기술 메모

- 모듈 분리: `members.py`(회원·권한·초대·동의·온보딩) — 정산 엔진(`engine.py`)과 독립. CMS 모듈 원칙 준수.
- 저장소: `data/users.json`, `data/invites.json` (기존 마스터와 동형 JSON).
- 비밀번호: pbkdf2-hmac-sha256 20만 회(외부 의존성 없이 stdlib).
- 세션: 서명 쿠키(SessionMiddleware). 시크릿을 파일 영속화 → **재시작해도 로그인 유지**(로컬), 배포는 `SESSION_SECRET` 환경변수 권장.
- 인증 페이지: `static/auth_login.html` `auth_register.html` `auth_invite.html` (Zoom풍 블루/화이트, 독립 페이지).
