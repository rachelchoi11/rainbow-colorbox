# 작업 기록 보고서 — 고도화 단계 (파일럿 → 정산마감 → 서비스기능)

- 작성일: 2026년 8월 2일 · 작성자: 최혜윤 · rachel@hive-mind.kr
- 범위: 회원/권한 완성 이후 **고도화 단계** 전 과정(가상 파일럿·보안·저장소·정산마감·회사정보·분석·운영자동화).
- 원칙: 각 작업 = 무엇/왜/어떻게/검증. 회귀 불변식 431,296행·99.50%·검증 86건은 전 과정 유지.

---

## 1. 가상 파일럿 + 리뷰 (피드백 수집)
- **무엇**: 라이브 앱에 3개 에이전트 투입 — 계약사(김실장)·운영자(정운영) 페르소나로 실 API 사용 + 아키텍처 리뷰.
- **왜**: 화면만 보면 안 드러나는 실사용 마찰·보안 구멍을 실제로 뚫어보게.
- **결과(핵심)**: 서버측 테넌트 격리 부재(직전 세션 조치)·**초대 권한상승**·**동의 미강제**·명세서 요율 크로스테넌트·유통사율 저장 권한·JSON 무락·데이터 소멸(재시작)·정산 영구'예상'.

## 2. 파일럿 발견 보안 구멍 → 즉시 수정 (검증 완료)
| 구멍 | 조치 |
| --- | --- |
| 초대로 운영사 최고관리자 무승인 발급 | 초대는 **계약사 계정만**(운영사는 가입+승인) |
| 동의가 UI뿐, 미동의자도 전체 정산 조회 | **동의·온보딩 서버 강제**(미완료 계약사 데이터 API 403) |
| 명세서 요율이 전 테넌트에서 매칭 | 테넌트 스코프로 제한 |
| 조회전용 담당자가 유통사율 저장 | 관리권한 필요로 |
- 하드닝: 마스터 원자적 쓰기, 비번 8자 일치, 계약 버튼 권한 게이팅.

## 3. 저장소 이전 (B2 — SQLite)
- **무엇**: 마스터(출판사·계약·회원·초대·플래그·별칭 등)를 JSON 파일 → **SQLite(WAL)**.
- **왜**: JSON은 재시작 시 소멸·동시 쓰기 clobber·크래시 시 빈 파일화(파일럿 중 계약 4→0 실측). 
- **어떻게**: `db.py` 문서-블롭 저장소(컬렉션 전체를 트랜잭션 교체). 최초 기동 시 JSON 1회 자동 이관. `load_*/save_*` 시그니처 유지 → 호출부 무변경.
- **검증**: 이관(출판사 128·회원 2 등)·라운드트립·회귀 유지.

## 4. 정산 마감/원장 (B3 — 핵심 가치)
- **무엇**: 그 달 지급액을 **확정=불변 스냅샷**으로 고정(초안→확정→지급). 선인세(MG)는 **이월 원장**으로 관리.
- **왜**: "정산 시스템"은 지급액이 재현 가능·불변이어야. 매번 재계산되는 추정치는 지급 근거가 못 됨.
- **어떻게**: `settlement_run` + 라인 스냅샷 + 이전 확정 런 MG 회수액 승계.
- **검증**: 런1 MG 5천만 상계→지급 21,990,569 / 확정 후 런2 MG 이월(상계0)→70,340,569. 이중 차감 없음.

## 5. 회사정보 자가관리 · 삭제 (P2·P5)
- **무엇**: 계약사가 사업자번호·대표자·주소·**정산 입금계좌**·세금계산서 이메일을 스스로 입력. 회원/출판사 삭제.
- **왜**: 정산 SaaS 필수 정보 수집. `org:manage_own`(정의만 됐던 죽은 권한) 활성화. 잘못 만든 계정 정리.
- **검증**: 자사만 수정·타사 차단·본인/마지막 최고관리자 삭제 방지.

## 6. 확인·결정 문서 (Rachel용)
- **이해 보고서**(무엇/지금동작/왜/⚠️결정) + **결정 체크리스트 엑셀**(배포본 이후 전 기능 59항목 ○/△/✕) + **서비스 영역 고도화 설계**.
- **왜**: 비개발자 관점에서 확인하고 유지/수정/삭제를 결정할 수 있게.

## 7. 데이터 분석 (서비스 고도화 4)
- **무엇**: "성과 분석" 화면 — 월별 추세·전월대비(MoM)·유통사 성과(정산액·비중·추정정산율·전월대비)·상위 작가/작품 파레토·집중도·유통대행 비중.
- **왜**: 출판사·운영자가 "지난달 대비 왜 늘고 줄었나"에 답. (돈 내는 주체=출판사 우선)
- **검증**: 운영자 전체 12억 / 계약사 스토린랩 6억(스코프). MoM +4.9%.

## 8. 운영 자동화 (서비스 고도화 3 — 자체 가능분)
- **수집 현황판**: 유통사 31곳×4개월 매트릭스(검증76/미검증48/미수신0). 어느 유통사가 언제 안 왔는지·검증됐는지.
- **이상 탐지**: 전월 대비 급변±40%(23건)·유통사 누락·음수·합계불일치·파싱오류·미검증 65/151.
- **마감 스케줄러**: 확정계약 보유 출판사별 마감 현황(완료/미마감), 마감일(기본10일)·대상월·리마인더 설정, 백그라운드가 마감일 경과+미마감 시 하루1회 감사 리마인더. '마감하기'→해당 테넌트 정산마감 이동.
- **왜**: 운영 최대 병목(수집 추적·품질 검증·마감 누락)을 시스템이 대신. 외부 의존 없이 구현.

## 9. 세무·지급 연동 (검토)
- 원천징수 지급명세서·전자세금계산서는 **팝빌(링크허브)·바로빌·더존** API로 가능(신뢰처). 계좌 실명확인·대량이체는 오픈뱅킹/펌뱅킹.
- 사업자 인증·파트너 계약 필요 → **파트너 결정 후 착수**.
