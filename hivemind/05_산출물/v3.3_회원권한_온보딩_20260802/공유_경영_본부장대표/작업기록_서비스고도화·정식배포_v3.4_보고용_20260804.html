작업 기록 보고서 — 서비스 고도화 및 정식 배포 (v3.4)

  • 작성일: 2026년 8월 4일 · 작성: 최혜윤(기획·PO 총괄) · rachel@hive-mind.kr
  • 범위: 회원·권한 완성 이후 고도화 전 과정 + 정식 배포·운영 체계
  • 품질 기준: 정산 정확도 불변식(431,296행 · 완전매칭 99.50% · 원본 대사 검증 86건) 전 과정 유지

1. 파일럿 · 취약점 조치

  • 취약점 발견·조치 완료(검증)
취약점조치
초대로 운영사 최고관리자 무승인 발급초대는 계약사 계정 전용, 운영사는 가입 후 승인
동의가 화면뿐, 미동의자도 전체 정산 조회동의·온보딩 서버 강제(미완료 계약사 데이터 API 403)
명세서 요율이 전 테넌트에서 매칭테넌트 스코프로 제한
조회전용 담당자가 유통사율 저장관리 권한 필요로 상향
  • 하드닝: 마스터 원자적 쓰기 · 비밀번호 8자 통일 · 계약 버튼 권한 게이팅

2. 저장소 이전 — SQLite

  • 마스터(출판사·계약·회원·초대·플래그·별칭 등) SQLite(WAL) 이전 완료
  • 최초 기동 시 기존 JSON 1회 자동 이관, 호출부 무변경
  • 재시작·동시 쓰기·크래시에도 데이터 보존
  • 검증: 이관(출판사 128 등) · 라운드트립 · 회귀 불변식 유지

3. 정산 마감 / 원장

  • 월 지급액 확정=불변 스냅샷(초안 → 확정 → 지급), 선인세(MG) 이월 원장
  • 검증: 런1 MG 5천만 상계 → 지급 21,990,569원 / 확정 후 런2 MG 이월(상계 0) → 70,340,569원, 이중 차감 없음

4. 회사 정보 자가 관리 · 삭제

  • 계약사 자가 입력: 사업자번호 · 대표자 · 주소 · 정산 입금계좌 · 세금계산서 이메일
  • 회원·출판사 삭제(자사만 수정, 마지막 최고관리자·본인 삭제 방지)

5. 성과 분석

  • 월별 추세 · 전월 대비(MoM) · 유통사 성과(정산액·비중·추정 정산율) · 상위 작가/작품 파레토 · 집중도 · 유통대행 비중
  • 계약사 자사 스코프 / 운영자 전체 스코프

6. 운영 자동화

  • 수집 현황판: 유통사 31곳 × 월 매트릭스(검증/미검증/미수신)
  • 이상 탐지: 전월 대비 급변 ±40% · 유통사 누락 · 음수 · 합계 불일치 · 파싱 오류
  • 마감 스케줄러: 출판사별 마감 현황, 마감일·대상월·리마인더 설정, 백그라운드 감사 리마인더

7. 정식 배포 — Railway 영속 볼륨

  • 영속 볼륨 정식 배포, 상태(SQLite·세션·계약 첨부) 전부 볼륨 저장 → 재배포에도 계정·데이터 보존
  • 환경변수 분리(세션 시크릿·DB 경로·첨부 경로·API 키), 시크릿 코드·저장소 미포함
  • 최초 시드: 운영사 최고관리자 · 정산 1~4월(431,296행) · 출판사 128곳 · 계약사 데모 1곳
  • 접속: https://hivemind-production-b8eb.up.railway.app

8. 접속 게이트 분리 · 계약사 자체 계약 관리

  • 접속 게이트 분리: 운영사=회원가입 후 승인 / 계약사=초대 링크 발급(초대는 계약사 전용)
  • 계약사 자체 관리: 출판사관리자가 자사 계약·정산 마감 직접 관리(담당자는 조회 전용)
  • 자사 스코프 강제: 계약·마감 쓰기 10개 지점 소유 검사(타 출판사 생성·수정·삭제·마감 403), 전사 마감 현황은 운영사 전용
  • 검증(라이브 6종): 자사 생성/삭제 200 · 타사 생성/수정/삭제 403 · 전사 마감현황 403 · 운영자 전 테넌트 유지

9. 운영자 콘솔 홈 재편

  • 정산 요약 홈에 고객사(출판사)별 정산 1차 블록 신설(행 클릭 시 해당 고객사 화면 이동), 유통사별·상위 작가 2차 배치
  • 운영자 역할 토글 라벨 명확화: 운영자 콘솔 / 고객사 화면

10. 브랜드 · UI

  • 브랜드 심볼(금색 헥사) 로고 전면 적용, 로그인 화면 개편(다크), 내부 화면 라이트 유지

11. 세무 · 지급 연동 (검토)

  • 원천징수 지급명세서·전자세금계산서: 팝빌(링크허브)·바로빌·더존 API로 구현 가능
  • 계좌 실명 확인·대량 이체: 오픈뱅킹/펌뱅킹
  • 사업자 인증·파트너 계약 선행 → 파트너 결정 후 착수

12. 남은 과제 · 로드맵

  • 🔴 정식 오픈 전: 로그인 시도 제한(레이트리밋) · SMTP(초대·알림 메일 실발송)
  • 🟡 후속: 작가 마스터+명세서 자동 배포(SMTP 후) · 세무 연동(파트너 후) · 자동 마감 생성(정산 데이터 영속화 후) · 페이지네이션·계약 일괄 편집 · 공개 API/웹훅
  • 참고: Railway 영속 볼륨(기존 최우선 인프라 과제)은 완료
