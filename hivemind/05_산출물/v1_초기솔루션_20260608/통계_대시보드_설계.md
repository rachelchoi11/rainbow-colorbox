# 정산 표준화 솔루션 — 기능 현황 및 시연 시나리오

- 최신화: 2026-06-08
- 대상 데이터: 2026년 2–3월 정산서 69개 파일 / 유통사 28곳 / 145,018 레코드 (실데이터, 원본 합계 검증 완료)

---

## 1. 구현 완료 기능 (전체)

### 데이터 처리
- 유통사별로 제각각인 정산서(형식 6종·인코딩 상이)를 업로드 → 자동 표준화
- 원본 합계 대사 검증 (합계 보유 40개 파일 전수 일치)
- 작품명 정규화(회차·권·태그·띄어쓰기 통합), 작가명 정규화([정천]=정천, 이윤정(탠저린)=이윤정 (탠저린))

### 화면 (좌측 메뉴)
| 메뉴 | 내용 |
|---|---|
| 정산 요약 | 작가 지급 대상 정산액, 월별 매출·정산액 막대(각 수치), 단행본/연재 구성, 검증 현황, 유통사·작가 미니 순위 |
| 통계 분석 | 차트 10종 — 유통사 도넛·매출→정산 폭포·레이블별·작품별·작가 파레토·유통사×유형 히트맵·장르(부분) 등 |
| 유통사별 | 유통사별 정산액·정산율·작가 수, 드릴다운(해당 유통사 상위 작가) |
| 작가별 | 작가별 정산액 + 근거 드릴다운(작품×유통사×월별 산출 근거), 기간 필터, 작가별 엑셀·정산서 발행 |
| 작품별 | 작품(시리즈) 단위 정산액·작가·레이블·유통사, 드릴다운(유통사·월별 내역) |
| 통합 검색 | 작가명·작품명 검색 — 같은 작품이 어느 유통사에 어떤 작가로 있는지(작가 보유 여부 표시) |
| 미매칭 | AI 제안(작가 자동 추천)·승인/거절·결정 히스토리, 전체 미매칭 목록, 번들 제외 토글 |

### 핵심 차별 기능
- **작가별 정산 근거**: "작가에게 얼마를, 어느 유통사/작품에서, 왜(제공값/계산값)" 추적
- **AI 미매칭 제안**: 다른 유통사·유사 작품·시리즈 형제작에서 작가를 찾아 신뢰도·근거와 함께 제안 → 담당자 승인 시 이후 자동 반영, 모든 결정 히스토리 보존
- **정산서 발행**: 작가별 정산 명세서(인쇄/PDF) — 유통사 선택·기간 선택, 원천징수 3.3%·실지급액 포함
- **상단 필터**: 유통사·기간 필터에 모든 화면·차트 실시간 연동
- **엑셀 내보내기**: 전체/작가별

## 2. 기존 Power BI 의도 대비 (통계)

기존 파일(2025년 자체 출간작 매출 정리) 내부 정의 추출 결과, 입금액(매출)을 시간·장르·레이블·유통사·작품·출간연도로 나눈 매출 분석이었습니다.

| 기존 그래프 8종 | 신규 반영 |
|---|---|
| 매출 추이·판매처별·브랜드별·작품별·총입금액 | ✅ 반영 (매출 추이는 매출+정산액 동시로 개선) |
| 분야별(장르) | △ 부분 (제공 유통사 한정) |
| 출간연도별·대상 작품수 | ✖ 제외 (정산서에 출간일 없음) |

신규 추가(정산 솔루션 강점): 작가별 정산·근거, 작가 파레토, 매출→정산 폭포, 유통사×유형 히트맵.

## 3. 시연 시나리오 (발표용)

> 권장 흐름: **업로드 → 요약 → 통계 → 작가 근거 → 정산서 → 미매칭 AI → 검색**. 각 단계 1–2분.

**① 표준화 (업로드)**
- 업로드 화면 → "26년 2·3월 샘플로 둘러보기" 클릭
- 멘트: "유통사 28곳, 형식이 제각각인 정산서 69개를 그대로 넣어 자동 표준화합니다."

**② 정산 요약**
- 큰 숫자(작가 지급 대상 정산액)와 월별 막대(2월·3월 매출/정산액) 제시
- 멘트: "원본 합계와 자동 대사해 40/40 일치 검증을 거친 실데이터입니다."

**③ 통계 분석**
- 매출→정산 폭포, 유통사 도넛, 작가 파레토(상위 10명 36%) 짚기
- 상단 유통사 필터를 바꿔 차트가 즉시 갱신되는 것 시연
- 멘트: "기존 Power BI 지표를 모두 담고, 작가 중심 분석을 더했습니다."

**④ 작가별 정산 근거** (핵심)
- 상위 작가 클릭 → 작품×유통사×월별 정산액과 산출 근거(제공값/계산값) 드릴다운
- 멘트: "작가에게 얼마를 왜 줘야 하는지, 유통사 원본까지 추적됩니다."

**⑤ 정산서 발행**
- 같은 작가 화면에서 유통사 선택 → "정산서 발행" → 명세서(원천징수·실지급액) → 인쇄/PDF
- 멘트: "작가에게 보낼 정산 명세서를 바로 발행합니다."

**⑥ 미매칭 AI 제안** (핵심)
- 미매칭 → AI 제안 탭: "월야환담 광월야", "정령왕 엘퀴네스 외전" 등 신뢰도·근거와 함께 제안
- 승인 시연 → 잔여 감소, 결정 히스토리 확인
- 멘트: "AI가 다른 유통사·유사 작품에서 작가를 찾아 제안하고, 담당자가 승인하면 이후 자동 반영됩니다. 모든 결정은 이력으로 남습니다."

**⑦ 통합 검색**
- "월야환담" 검색 → 유통사별 작가 보유 여부(✓) 확인
- 멘트: "한 작품이 어느 유통사에 어떤 작가로 들어있는지 한눈에 봅니다."

## 4. 데이터 한계 (투명 고지)
- 출간연도별 통계: 정산서에 출간일 없음 → 제외 (작품 마스터 입력 시 가능)
- 장르별: 일부 유통사만 제공 → 부분 집계
- 정산서 작가 요율: 데이터엔 유통사→출판사 정산액만 존재 → 작가 계약 요율은 입력값(기본 100%)
