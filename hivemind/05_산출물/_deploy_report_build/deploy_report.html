1. 배포 전 상태 — 로컬 vs 운영(프로덕션)

그동안 고도화(v2)는 로컬(개발 환경)에서 진행했고, 운영 서버는 아직 초기 버전(v1)으로 가동 중이었습니다. 이번 배포는 그 둘 사이의 격차를 운영 서버에 반영하는 작업입니다.

2. v2 반영 중 발견한 이슈와 조치

이슈 1 — 로컬에서 누락된 안전장치 2종

  • 예스24·판무림 정산 산식 (매출·정산액 환산식) — 누락 시 해당 유통사 금액이 빈값으로 회귀
  • 메모리(OOM) 안전장치 — 누락 시 과거 발생했던 서버 다운(502)이 재발할 위험. 데이터가 3배로 커져 위험도가 더 높음

이슈 2 — 로컬과 운영의 폴더 구조 상이

조치 항목

  • 안전장치 2종 재병합 — 정산 산식과 메모리 안전장치를 v2에 다시 얹어, 유실 없이 반영
  • 운영 구조에 맞춰 재조립 — 경로를 환경변수 기반으로 정리하여 운영 서버에서 그대로 동작하도록 조정
  • 데이터 재생성 — 산식이 반영된 1~4월 데이터(43.1만 행)를 다시 생성. 공식 통합본과 수치 일치 확인
  • 전수 점검 — 로컬에서 로그인·집계 수치·신규 기능(연구소·일괄처리)까지 전수 정상 확인
  • 롤백 안전망 확보 — 문제 발생 시 직전 상태로 즉시 되돌릴 수 있도록 복원 지점 보존
