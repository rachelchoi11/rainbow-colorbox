## A. 확인 완료 (참고 — 별도 회신 불필요)

- **다수 컬럼 합산 플랫폼**(리디·미스터블루·애니툰·원스토리·카카오페이지·판무림): 판매유형별로 흩어진 정산액 컬럼을 합산한 결과가 **원본 정산서의 자체 합계행과 ±1원 이내로 전수 일치**함을 확인했습니다. → 정산액 합산 기준 검증 완료.

## B. 확인 요청 (6건) — 체크만 부탁드립니다

### 1. 문피아 — 작품명 말미 태그 `[D]` / `[E]`
- **데이터 확인**: 작품명 끝에 `[D]`(178건)·`[E]`(53건)·태그없음(156건)이 혼재합니다. 유의사항 문서의 "[단행본] 표기"와 실제 표기가 다릅니다.
- **질문**: `[D]`·`[E]`의 의미와, 단행본/연재 구분 기준을 알려주세요.
  - ☐ `[D]`=단행본 / `[E]`=□______ / 태그없음=□______
  - ☐ 기타: ________________________________

### 2. 올툰 — 단행본/연재 구분
- **데이터 확인**: 작품명 접두는 `[소설]`·`[BL소설]`(장르 표시)뿐이고, 단행본/연재를 나누는 컬럼이나 표기가 없습니다(문서엔 "'타입' 항목으로 구분"으로 기재).
- **제안**: 올툰 전 작품을 **단행본으로 일괄 처리**하겠습니다.
  - ☐ 맞음 (전부 단행본)  ☐ 아래 기준으로 구분: ________________

### 3. 판무림 — "단행본만"인지
- **데이터 확인**: 대분류 컬럼에 **연재(1,530건)·단행본(448건)이 모두** 있습니다(문서엔 "단행본만").
- **제안**: 문서 기재와 달리, **대분류 컬럼 값(연재/단행본)을 그대로 사용**하겠습니다.
  - ☐ 맞음 (대분류 값 사용)  ☐ 기타: ________________

### 4. 피우리 — 판매형태 처리
- **데이터 확인**: 판매형태가 **단권(1,430건)·대여제(20건)**이며, 연재 개념이 없습니다(이 플랫폼은 유의사항 문서에 항목이 없었습니다).
- **제안**: 단권·대여제 모두 **단행본으로 처리**(대여제는 판매방식 차이일 뿐)하겠습니다.
  - ☐ 맞음  ☐ 기타: ________________

### 5. 구루컴퍼니 / 알라딘 — 문서 항목 확인
- **데이터 확인**: 유의사항 문서의 **두 번째 '구루컴퍼니' 항목**("정가 100원 + 화수 표기 = 연재")은, 형식·내용상 실제로는 **알라딘**에 대한 설명으로 보입니다.
- **질문**: 해당 항목이 알라딘 설명이 맞습니까? (저희는 알라딘에 그 규칙을 적용 중입니다)
  - ☐ 맞음 (알라딘 설명)  ☐ 아님: ________________

### 6. ★ 네이버시리즈 — 마켓수수료 추정 기준 (정산액에 직접 영향)
- **데이터 확인**: 네이버시리즈는 정산금액을 직접 주지 않아, 저희가 **[합계 − 마켓수수료] × 0.7**로 계산하고 있습니다. 이때 **마켓수수료(앱 인앱결제 수수료 등) 추정 기준**이 필요합니다.
- **질문**: 마켓수수료를 어떻게 잡을지 기준을 주세요. (예: 합계의 N%, 또는 별도 제공 자료)
  - ☐ 합계의 ______ % 차감  ☐ 별도 자료 제공 예정  ☐ 기타: ____________
