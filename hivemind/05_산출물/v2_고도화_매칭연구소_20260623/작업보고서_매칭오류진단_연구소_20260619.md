## 1. 발견 사례 — 동명이작 과병합 (작품별 #128)

`부장님 왜 이러세요`(norm=`부장님왜이러세요`) 한 항목에 작가·레이블이 2개씩 표시 → 실제로는 **다른 두 작품**:

| 작품 | 작가 / 레이블 | 정산액 | 플랫폼 |
|---|---|---|---|
| 부장님 왜 이러세요 [개정판] | 주황연 / 리체북스앤미디어 | ~975,000 | 원스토리·예스24·알라딘·북큐브 등 8곳 |
| 부장님, 왜 이러세요? | 창작집단 뻘 / BOOK 19 | ~750 | 미스터블루·원스토리 |

**원인**: 제목 정규화가 **구두점(쉼표·물음표)·띄어쓰기를 제거** → `부장님 왜 이러세요` = `부장님, 왜 이러세요?` 로 충돌. 작품 식별 키가 `title_norm` **단독**이라 작가/레이블이 달라도 한 작품으로 병합됨.

**핵심 판단**: 구두점을 정규화에서 되살리면 안 됨 — 구두점/띄어쓰기 변형은 *같은 작품*인 경우가 훨씬 많아 과분리를 유발. 해법은 **작가·레이블·ISBN로 식별 보강** + 의심건 사람 검토.

## 2. 매칭 규칙 오류 가능성 — 전수 카탈로그

> 우리 파이프라인의 각 규칙이 "틀릴 수 있는 경로"를 모드별로 정리. 각 모드 = 원인 / 증상 / 측정·예시 / 자동 탐지법 / 처리법.

### E1. 동명이작 과병합 (정규화 충돌)
- 원인: title_norm 단독 키 + 구두점/띄어쓰기 제거
- 증상: 한 작품에 disjoint한 (작가·레이블) 클러스터 2+개
- 측정(1~4월): **진짜 동명이작 116건 / 위험액 718,293원(0.06%)**
- 탐지: title_norm별 작가(강축약) 2+개 **AND** 클러스터별 레이블이 서로 disjoint
- 처리: 작품 키 = `title_norm+작가`로 분리 + 검토 큐 승인(자동분리 오판 방지) + ISBN 우선

### E2. 작가 표기변형 미축약 (가짜 동명이작·과탐)
- 원인: 한자병기(`필환(筆煥)`)·영문병기·구두점·공동작가(`글작소`↔`글바랑 글작소`)를 author_norm이 못 잡음
- 증상: 같은 작품에 작가 여러 명(실제 동일인)
- 측정: 단순 "작가 2+" 489건 중 **약 373건이 이 경우**(116건만 진짜)
- 탐지: 작가들이 강축약 시 동일 / 레이블 공유 / 부분문자열
- 처리: **작가 정규화 강화**(괄호병기·구두점·공백·공동작가 축약) — 저위험·고효과

### E3. 레이블(출판사) 표기변형 미축약
- 원인: `마야&마루`=`마야마루출판사`, `심월`=`심월(心月)` 등
- 증상: 한 작품·출판사가 여러 레이블로 분산 (출판사별 집계 분산)
- 탐지: 레이블 fuzzy 동일(괄호병기·법인격 접미 제거 후 일치)
- 처리: 레이블 정규화 규칙 + 출판사 별칭 테이블

### E4. 잘못된 교차참조 backfill
- 원인: 작가 미제공 행을 title_norm 다수결로 채우는데, **동명이작이면 틀린 작가 귀속**
- 증상: 예스24 등 무작가 행이 엉뚱한 작가로 채워짐
- 탐지: backfill 출처가 동명이작(E1) 작품 + 단일 출처
- 처리: E1 분리 선행 + backfill 신뢰도 표기(원천/당월대조/과거자산) 노출

### E5. 번들/구독 오분류
- 원인: `원스토리 패스·북패스` 등 채널정기권을 작품으로(미탐) 또는 실제작품을 번들로(오탐, 예: '삼국지 싸이코패스')
- 측정: 번들 정상 분리 20행/2.73M (현재 키워드 정밀지정)
- 탐지: 번들 키워드 경계 검토 + settle/행수 이상치
- 처리: 번들 사전 보강 + 의심건 검토 큐

### E6. book_type(단행본/연재) 오판
- 원인: 각주 미확정 — 문피아 `[D]`/`[E]`, 올툰 장르태그(`[소설]`), 피우리 `대여제`
- 증상: 같은 작품이 플랫폼마다 단행본/연재 엇갈림
- 탐지: 같은 title_norm에 book_type 혼재 / 태그 규칙 불일치
- 처리: **각주 확인서 회신 반영**(확인요청서_정산서표준화) 후 규칙 확정

### E7. 권/회차 통합 누락·과통합
- 원인: `28권`/`29권` 통합 규칙 vs 부제 다른 형제작(`광월야`/`채월야`) 분리 경계
- 증상: 분리돼야 할 게 합쳐지거나, 합쳐져야 할 게 분리
- 탐지: base title 동일하나 부제 분기 / 권번호만 다른 잔여 미매칭
- 처리: 시리즈 별칭 등록 + 검토

### E8. 합산·대사 사각지대
- 원인: 합계행 없는 파일은 원본 대사 불가
- 측정: 1~4월 **합계행 없음 65개 파일**(검증 못 함)
- 탐지: expected_settle=None
- 처리: 교차검증(03 수정본)·월간 추세 이상치로 보조 검증

### E9. 정산액 계산값 추정 오차
- 원인: 네이버 `(합계−마켓수수료)×0.7`, 블라이스 `×0.7`, 조아라 `단가×건수` 등 추정
- 증상: 마켓수수료 기준 미확정 → 정산액 오차
- 탐지: settle_basis=계산값 행 집계
- 처리: **네이버 수수료 기준 확인서 회신** 반영

### E10. 미매칭 단독작
- 원인: 작가·레이블 모두 미제공 + 교차단서 없음(예스24 단독작)
- 측정: 미매칭 246행(번들제외 0.06%)
- 처리: AI 제안·알라딘 조회·수동 등록(승인제, 자동적용 안 함)

## 3. 연구소(Lab) — 상시 개선 루프

> **신고 → 수집 → 진단 → 규칙 반영 → 재측정** 의 닫힌 루프. 결과값을 보다가 이상하면 즉시 신고, 연구소에 모여 다시 검토.

```
[결과 화면] 🚩 신고(사유 분류+메모)  ─┐
[자동 탐지기] E1·E6·E8·E9 의심건 ──┤→ [연구소] 모음·상태관리(열림→검토중→규칙반영/기각)
                                  │      └ 진단 메모 + 규칙 반영 기록(감사추적)
                                  └────────────── 재측정으로 효과 확인 ←┘
```

- **신고 버튼**: 작품별·작가별 등 결과 행에 🚩 — 사유 분류(동명이작/작가오류/레이블오류/번들/book_type/기타) + 메모 → `flags.jsonl` 기록
- **자동 탐지기**: 카탈로그의 측정 가능한 모드(E1 동명이작, E6 book_type 혼재, E8 대사사각, E9 계산값) 자동 추출 → 연구소에 의심건으로 적재
- **상태 워크플로우**: 열림 → 검토중 → 규칙반영(또는 기각), 진단 메모 첨부
- **규칙 반영**: 확정된 진단을 정규화/스펙/별칭 규칙에 반영 → 재측정으로 줄었는지 확인

### 구현 범위 (v1)
- [x] 오류 카탈로그(본 문서)
- [ ] 🚩 신고 버튼 + `/api/flag` 기록
- [ ] 연구소 뷰: 신고 목록 + E1 자동탐지 + 상태/진단
- [ ] 추가 탐지기(E6/E8/E9) 점진 확장

### 우선순위(처리 효과 순)
1. **E2 작가 정규화 강화**(가짜충돌 ~373건 제거, 저위험) → 2. **연구소 + E1 검토 큐**(진짜 동명이작 116건) → 3. **E6/E9 각주 확인서 회신 반영** → 4. E3 레이블 정규화

## 4. E2 작가 정규화 강화 — 적용 & 전후 비교 (2026-06-22)

### 적용 규칙 (`normalize.norm_author`)
- 대괄호 태그 제거: `[정천]`=`정천`, `[BL]김작가`=`김작가` (단 전체가 `[..]`면 괄호문자만 제거해 빈값 방지)
- **한글 이름의 병기 통합**: `필환(筆煥)`=`필환`, `무영武映`=`무영`, `로체니콥(rocheni-cob)`=`로체니콥` (괄호 안에 한글 있으면 필명 가능 → 보존: `이윤정(탠저린)`)
- 끝/중간 구두점 제거: `로체니콥.`=`로체니콥`
- **안전장치**: 쉼표 보존(공동작가 `사마달,고월`은 별개 유지) · 순수 영문/숫자 이름(`Magoing`)은 한자·영문 제거 미적용(빈값 방지)
- 단위테스트 10케이스 전수 통과(통합 7 / 별개유지 3)

### 판정
- **정산 금액 영향 0원** — 작가 *식별 키*만 통합, 지급액 왜곡 없음(최우선 안전성 확인)
- **과탐만 정확히 제거** — 같은 작가 다른 표기 100명·68작품 통합, 진짜 동명이작 96건은 그대로
- 회귀 0 (2·3월 145,018행/69파일/문제0), 공식 통합본 재생성(완전매칭 99.5% 유지)
- 남은 동명이작 96건(위험액 473,761원)은 **연구소 E1 검토 큐**에서 사람 검토 → 작품키 분리(다음 단계)
