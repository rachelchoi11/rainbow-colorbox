# 작업 보고서 — 신규 정산 데이터 반영 및 솔루션 고도화 검증

- 작성일: 2026-06-19 | 작성: 최혜윤
- 대상: 신규 데이터(2026년 1·4월 + 교보문고·모픽·에이블리) 반영
- 요약: 신규 플랫폼·신규 월 정상 처리 확인. 2026년 1~4월 4개월 공식 통합본 산출(43만 행, 검증 전수 통과, 미매칭 정산액 0.08%).

---

## 1. 목적

신규 데이터를 솔루션에 반영하여 두 가지를 검증.

1. 정상 처리 여부 — 과거 자동 취합 불가로 분류했던 교보문고·모픽의 자동 처리 가능성, 신규 월(1·4월)의 무오류 처리.
2. 미매칭률 개선 여부 — 작가·레이블을 완전 제공하는 플랫폼(교보·모픽) 편입이 매칭 정확도에 미치는 영향.

원칙: 선(先)측정. 추측에 따른 선개발을 지양하고, 데이터로 확인한 범위만 구현.

---

## 2. 진행 및 결과

### 단계 1 — 신규 플랫폼 파서 등록 (교보문고·모픽)

- 실제 파일 구조 확인 후 파서 규칙(specs)에 등록.
  - 모픽: 작가·출판사·매출·정산액을 모두 제공. `제공사=스토린랩`(유통대행 신호) 포함.
  - 교보문고: B2B 기관 납품형으로 한 도서가 납품처별 다중 행 → 합산 처리. ISBN 보유(작품 식별 정밀 키).
- 결과: 교보문고 원본 합계와 자동 대사 정확히 일치(1월 2,155,698원 / 4월 3,035,099원), 모픽 정상 처리.

### 단계 2 — 신규 월(1·4월) 전수 처리

- 78개 파일 처리 중 파일명·양식 변동 4건 발견·수정.

| 항목 | 내용 | 조치 |
|---|---|---|
| 원스토어 | "원스토리"에서 "원스토어"로 명칭 변경 | 두 표기 모두 인식 |
| 로망띠끄 | "단행본"→"전자책", 파일명 오타 | 표기 변형 수용 |
| 노벨피아 | 상세 양식 파일 명명 변경으로 매칭 누락 | 매칭 규칙 보정 |
| 알라딘 B2B | 기관 납품 양식(도서명/정가합)이 기존과 상이 | 양쪽 양식 모두 수용 |

- 결과: 78파일 전부 처리, 오류 0건, 합계 대사 실패 0건.

### 단계 3 — 미매칭 진단 (선측정)

- 잔여 미매칭의 원인을 먼저 분석한 결과, ISBN 매칭은 해당 미매칭의 해법이 아님을 확인.
  - 미매칭 178행 = 예스24(157) + 올툰(11) + 원스토리(10). 전부 작가·레이블 미제공 단독작이며 ISBN 부재 → ISBN 연결 대상 없음.
  - 최대 미매칭 금액(원스토리 약 160만원)은 구독 번들(원스토리 패스)로 작품 대상 아님.
- 시사점: ISBN은 미매칭 축소 수단이 아니라 작품 식별 정확도(작품 마스터)의 자산. 측정을 통해 불필요한 개발을 사전 차단.

### 단계 4 — 운영 매칭 레이어 검증

- 솔루션 엔진의 번들 분리 기능에 신규 데이터를 적용한 결과, 원스토리 패스가 번들로 분리되어 미매칭 정산액 0.4% → 0.1%로 감소.

### 단계 5 — 1~4월 공식 통합본 산출 (다중소스 파라미터화)

- 입력 소스를 설정으로 분리하여 4개월 데이터를 통합.
  - 1·4월: 신규 완전판(교보·모픽 포함).
  - 2·3월: 기존 원본 + 교보·모픽 추가(에이블리는 기존 폴더와 중복이라 제외 → 정산액 이중 계상 방지).
- 산출물: `output/2026_정산통합_1to4_v1.xlsx`(6개 시트).

### 3-2. 미매칭률 개선 검증

- 신규 플랫폼(교보·모픽)을 공유 마스터에 포함 시 다른 플랫폼의 완전매칭이 +1,517행 증가(부분 → 완전 승격), 미매칭 −38행.
- 교보·모픽의 가치는 작가·레이블을 완전 제공하는 플랫폼으로서 다른 플랫폼의 결측을 보강하는 데 있음. 미매칭 절대 수치는 이미 99%대로 변동폭은 작음.
