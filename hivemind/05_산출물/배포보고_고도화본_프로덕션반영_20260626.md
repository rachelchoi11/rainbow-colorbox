그간 로컬에서 개발해온 고도화본을 프로덕션(Railway)에 반영 완료했습니다.

**1. 반영 내용 (로컬 → 프로덕션)**
- 데이터: 26년 2·3월(14.5만 행) → 1~4월 통합본(151파일·43.1만 행)
- 유통사 확대: 모픽·교보문고 추가 (총 31개 유통사)
- 매칭 고도화: 작가 정규화 강화(한자·영문 병기 통합) → 완전매칭 99.5%, 미매칭 정산액 0.08%
- 신규 기능: 미매칭 보드 일괄승인·복원(감사추적 유지), 매칭 연구소(동명이작 자동탐지 + 신고 워크플로우)

**2. 배포 중 발견·해결한 문제**
- 로컬 개발본이 프로덕션보다 이른 시점에서 갈라져 나와, 프로덕션에만 적용돼 있던 안전장치 2종이 로컬본에 빠져 있었음. 그대로 올렸다면 기능 퇴행 발생.
  - 예스24·판무림 정산 산식(매출=정산액÷0.7 / 정산액=판매금액×0.7): 누락 시 해당 매출·정산액이 빈값으로 회귀
  - 메모리(OOM) 안전장치(세션 상한): 누락 시 과거 502 크래시 재발 위험 — 데이터가 3배로 커져 위험도 상승
- 두 안전장치를 신규 개발본에 다시 병합하여 유실 없이 반영.
