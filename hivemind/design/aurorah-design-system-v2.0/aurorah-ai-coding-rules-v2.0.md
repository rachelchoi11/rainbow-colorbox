# Aurorah 정산 콘솔 · AI 코딩 지침 (v2.0)

AI 코딩 툴(Claude, Copilot 등)로 UI 작업 시, 프롬프트 또는 프로젝트 지침 파일(CLAUDE.md 등)에 아래 단락을 그대로 포함하세요.

---

이 프로젝트의 모든 UI 스타일은 `aurorah-theme-v2.0.css`의 디자인 토큰(`--hm-*` CSS 변수)과 컴포넌트 클래스(`.hm-*`)만 사용한다. 임의의 색상 HEX, 임의의 px 간격·라운드·그림자·전환 시간을 새로 만들지 않는다 — 색은 반드시 `var(--hm-*)`, 간격은 `var(--sp-*)`, 라운드는 `var(--rad-*)`, 모션은 `var(--dur-*)` + `var(--ease)`를 참조한다. 브랜드 틸(`--hm-primary` #009999)은 정체성·차트·장식에 쓰고, 버튼 등 인터랙티브 면은 `--hm-primary-strong`(#008080)을 사용하며 틸 면 위 글자는 항상 흰색이다(#009999 위 흰색은 대비 미달이므로 인터랙티브 면에 #009999 직접 사용 금지). 흰 배경 위 틸 텍스트는 `--hm-primary-deep`(#007272)만 사용한다. 상태 표기는 색+텍스트 이중 표기가 원칙이고, 이미 정의된 컴포넌트(버튼·칩·표·폼·드로어·토스트·빈 상태·매트릭스 셀)는 새로 구현하지 말고 해당 `.hm-*` 클래스를 재사용한다. 차트는 `aurorah-chart-theme-v2.0.js`의 `HM_CHART` 값만 사용한다(범주색 순서 고정, 비교 기준은 `comparisonMuted`, 임의 색 생성 금지). 아이콘은 Lucide(lucide.dev)만 사용하고 유니코드 기호(▦ ✓ ⌕)나 이모지를 UI 아이콘으로 쓰지 않으며, 아이콘 색은 currentColor 상속으로만 처리한다. 표의 행 높이는 상수(여유형 60px/밀집형 40px)로 유지하고, 2줄 셀은 패딩 축소로 보상하며 셀 내부 모든 줄에 line-height 고정값을 지정한다. 반응형 컴팩트 규칙(@media)은 반드시 기본 규칙보다 뒤에 작성한다(소스 순서가 곧 우선순위). 여기에 없는 새 패턴이 필요하면 임의로 만들지 말고 먼저 질문한다.

## 검수 체크리스트 (코드 리뷰 시)

- [ ] 새 HEX 색상 코드가 등장하지 않는가? (`#`으로 grep — 토큰 파일 외 발견 시 위반)
- [ ] 인터랙티브 면에 #009999가 직접 쓰이지 않았는가? (버튼·필은 strong #008080)
- [ ] 흰 배경 위 틸 텍스트가 deep(#007272) 이외의 값으로 쓰이지 않았는가?
- [ ] 하드코딩된 transition 시간·easing이 없는가?
- [ ] 기존 `.hm-*` 컴포넌트가 있는데 새로 구현하지 않았는가?
- [ ] 상태가 색으로만 표현되지 않았는가? (텍스트 병기 확인)
- [ ] 유니코드 기호·이모지가 아이콘 자리에 쓰이지 않았는가? (Lucide만)
- [ ] @media 컴팩트 규칙이 기본 규칙보다 뒤에 있는가? (캐스케이드 순서)
