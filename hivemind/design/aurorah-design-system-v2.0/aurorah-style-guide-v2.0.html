01

디자인 원칙

정산은 금융입니다. 모든 화면·컴포넌트 판단은 아래 네 가지 기준으로 내립니다.

숫자가 주인공

금액·건수는 항상 고정폭 숫자(tabular numerals)로, 우측 정렬로. 색과 장식은 숫자를 읽는 데 방해되지 않는 선까지만 사용합니다.

상태는 한눈에

수신/미수신, 매칭/미매칭, 신뢰도 밴드 등 모든 상태는 색 + 텍스트 칩으로 이중 표기합니다. 색만으로 의미를 전달하지 않습니다.

층위는 그림자보다 보더로

데이터 밀도가 높으므로 무거운 그림자·그라데이션 대신 1px 보더와 배경 단차(백자 → 흰색)로 위계를 만듭니다.

움직임은 확인용

애니메이션은 '무슨 일이 일어났는지' 확인시켜 주는 역할만 합니다. 120–320ms, 한 화면에 동시 모션은 하나만.

시그니처 · 오로라 글로우 — 심해빛 다크 배경 상단에서 옥빛 광휘가 커튼처럼 번지는 그라데이션. 브랜드명 Aurorah의 오로라를 그대로 시각화한 장치로, 다크 로그인 배경(그리고 분석 홈 히어로)에만 사용합니다. 그 외의 장식 요소는 두지 않습니다 — 선택·활성 상태는 항상 옥 Soft 배경 + 짙은 텍스트로, 상태 성격은 아이콘 칩과 상태 칩의 색으로 전달합니다.

02

컬러 팔레트

브랜드 틸 옥 #009999(Aurorah 브랜드 색)를 축으로, 나머지는 틸와 어울리는 따뜻한 회색과 의미색만 사용합니다. 팔레트 이름은 한국 전통색에서 가져왔습니다 — K-콘텐츠를 다루는 브랜드다운 정체성이자, 토큰을 기억하기 쉽게 하는 장치입니다. 스와치를 클릭하면 HEX가 복사됩니다.
틸 사용 규칙: 브랜드 옥(#009999)은 정체성·차트·장식 면에 사용합니다. 버튼 등 인터랙티브 면은 한 단계 짙은 옥 Strong #008080을 쓰고, 틸 면 위 글자는 항상 흰색입니다(#008080 위 흰색 = 4.8:1, AA 통과 — #009999 위 흰색은 3.9:1로 미달). 흰 배경 위 틸 텍스트는 옥 Deep #007272만 사용합니다.

05

컴포넌트

정산 콘솔에서 반복 사용되는 모듈입니다. 실제 배포본 화면(업로드, 수집·점검, 미매칭 보드, 출판사·계약 관리, CP 대시보드)을 기준으로 작성했으며, 모든 상태(기본/호버/선택/비활성)는 실제 CSS로 구현되어 있으니 개발 시 이 문서의 소스를 그대로 참고하세요.

버튼

한 화면의 Primary 버튼은 1개가 원칙. 파괴적 동작(삭제·마감 취소)은 Danger 아웃라인.

상태 칩 · 배지

상태 의미와 색의 매핑은 제품 전체에서 고정입니다. 색 + 텍스트 이중 표기, 신뢰도 밴드는 점(dot)을 추가해 구분합니다.
