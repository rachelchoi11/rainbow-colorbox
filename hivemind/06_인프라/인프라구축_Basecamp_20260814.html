📌 Message Board — 프로젝트 개요 (그대로 붙여넣기)

목표: 지금까지 Rachel이 임시로 운영해 온 정산 솔루션을, 출판사에 정식 오픈 가능한 운영급 인프라로 세우고, 인프라 운영을 강수아에게 이관한다.

현재 상태:

  • 앱: FastAPI(Python) + 자체 프론트(바닐라 JS) + SQLite(Railway 볼륨). 라이브 배포 중, 매일 진화 중.
  • 리포: github.com/rachelchoi11/hivemind (강수아 협업자 등록 완료).

원칙:

1. 스택은 Python 유지 — 재작성 안 함. 핵심 자산(정산서 28종 파서·40만 행 처리)은 pandas(Python)가 최적이고, 이 규모의 B2B에선 서버 성능이 병목이 아님. 성능 벽이 실제로 오면 그때 뜨거운 부분만 최적화(파이프라인은 Python 유지).

2. 결정은 Rachel, 실행은 강수아. 블랙박스 금지 — 모든 변경은 PR + 무엇을/왜 설명 + Rachel 승인.

3. 출시 전 필수부터. 나머지는 백로그.

협업 도구: 이 Basecamp로 일원화(기존 디스코드 대체). 할 일·결정·논의는 여기서.
